AXIOM: an architecture studio brand and website design concept

By Kenil Vaghasiya · November 15, 2026 · 2 min read
  • Brand Design
  • Web Design
  • UI Design

An architecture website should give the work room to speak. AXIOM is a visual exploration of how an architecture studio can present its identity and its projects, with a minimal logo, expressive typography and monochrome imagery.

The idea

Architects are judged on their buildings, so the website's job is to get out of the way. AXIOM uses generous spacing to keep the layout calm, and a clear hierarchy that guides a visitor from the studio introduction straight to featured work.

Brand identity

  • Logo: a geometric letter "A" drawn from a few straight lines, above a widely spaced wordmark
  • Colour: black and white only, so the photography supplies all the tone
  • Typography: a large editorial serif for the headline, "Space, considered.", with a quiet sans serif for navigation and details

The desktop home page

The desktop layout gives project photography the most prominent place. Above it sits a short statement, "Architecture shaped around the way we live", and a link to discover the studio. Below, the first selected project is labelled plainly with its number, name, type and year, the way an architect would caption a drawing.

The mobile version

The mobile concept is not a shrunken desktop page. It uses a simpler stacked layout: logo and menu, headline, statement, one project image, then the project name with a clear "View project" link. Many people will first open a studio's site on a phone from a social profile or a referral, so that screen has to stand on its own.

What the presentation includes

  • A geometric logo and wordmark
  • A black-and-white visual identity
  • A desktop home page concept
  • A matching mobile website concept
  • Device mockups showing the full direction

About this concept

AXIOM is a design concept, presented through AI-assisted mockups. It is not a live website, and the architecture studio is fictional. I made it to show the direction I would take for a real studio, and I can build a direction like this as a working site in Next.js or Framer.
